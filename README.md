# ビンゴ スマートボール

縁日の「スマートボール」をブラウザで遊べる3Dゲームです。
発射棒を引っぱってビー玉を打ち出し、穴に入れてビンゴを狙います。

インストールもビルドも不要で、`index.html` を1つ開くだけで遊べます。

## 遊び方

1. タイトル画面でモードを選びます。
2. 画面を**下に引っぱって、離す**と玉が飛びます。引くほど強く飛びます。
   - 弱く打つと右寄りに、強く打つと左寄りに落ちます。
   - 強さゲージの白線は前回の強さです。同じ強さで打ち直すときの目安にしてください。
3. 玉が入った穴のマスが光ります。**たて・よこ・ななめ**の1列がそろえばビンゴです。
4. 玉を全部打ち終わるとゲーム終了です。

### モード

| モード | 盤面 | 玉の数 |
|---|---|---|
| かんたん | 3×3 | 10球 |
| ふつう | 4×4 | 20球 |

### ルール

- 玉が入った穴はふさがります。同じ穴に2回は入りません。あとから来た玉は上で弾かれます。
- 前の玉が盤に出ると、すぐ次の玉が装填されます。連続で打つことができます。
- 上まで届かなかった弱い玉はレーンに戻ってきます。玉は減らず、打ち直せます。
- あと1マスでそろう穴は赤く点滅します（リーチ）。

### 点数

| 内容 | 点数 |
|---|---|
| 新しい穴に入る | +10 |
| ビンゴ | 1列目 +100、2列目 +200、3列目 +300 … |
| 全マス点灯（パーフェクト） | +500 |

モードごとのベストスコアは、ブラウザに保存されます。

### 操作

| 操作 | スマホ | PC |
|---|---|---|
| 棒を引く | 画面を押したまま下へずらす | マウスで押したまま下へドラッグ、またはスペースキー / ↓キーを押し続ける |
| 発射 | 指を離す | マウスを離す / キーを離す |

## 起動方法

### いちばん簡単な方法

`index.html` をブラウザで開くだけです。

> Three.js（3D描画）とフォントをインターネットから読み込むので、ネットにつながった状態で開いてください。

### ローカルサーバーで開く場合

ブラウザの設定によって直接開けないときは、簡易サーバーを立てて開いてください。

```bash
# Python がある場合
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

### GitHub Pages で公開する

1. このリポジトリを GitHub に push します。
2. リポジトリの **Settings → Pages** を開きます。
3. Source に `main` ブランチの `/ (root)` を選んで保存します。
4. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

## 動作環境

- WebGL に対応したブラウザ（Chrome / Safari / Edge / Firefox の最近のもの）
- スマホ・PCどちらでも遊べます。縦長の画面ではカメラが上から見下ろす角度に、横長の画面では斜めから見る角度に自動で切り替わります。
- 重い端末では、光のにじみ → 解像度 → 影の細かさ の順に、自動で描画を軽くします。

## 技術メモ

- **1ファイル構成**：HTML・CSS・JavaScript をすべて `index.html` に入れてあります。ビルドは不要です。
- **3D描画**：[Three.js](https://threejs.org/) r160（jsDelivr から import map で読み込み）
  - 光のにじみ：UnrealBloomPass
  - 映り込み：RoomEnvironment
  - 影：シャドウマップ
- **物理**：自前の2D物理を使っています。傾いた盤の上を転がる玉の動きを、盤の平面上で計算します。
  - 釘・壁・アーチ・穴・玉どうしの衝突
  - 穴への吸い込み
  - 引っかかったときの自動脱出
- **音**：音声ファイルは使わず、Web Audio API で合成しています。
  - 転がる音、釘に当たる音、穴に落ちる音、ファンファーレなど
- **フォント**：Google Fonts の [Dela Gothic One](https://fonts.google.com/specimen/Dela+Gothic+One) と [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)

### コードの中の主な場所

`index.html` の中の `<script type="module">` に、すべてのコードが入っています。

| 探すもの | 内容 |
|---|---|
| `const SB = (() => {` | 物理エンジン（盤の配置、釘、穴、衝突、発射） |
| `MODES` | モードごとの盤の大きさと玉の数 |
| `BALL_R` / `PIN_R` / `HOLE_R` | 玉・釘・穴の大きさ |
| `function launch` | 引いた強さと玉の初速の関係 |
| `const sfx` | 効果音 |
| `function paintSurface` | 盤面の絵柄（色・模様・文字・番号） |
| `function buildBoard3D` | 盤・穴・釘の3Dモデル |
| `function onCapture` | 穴に入ったときの処理（点数・ビンゴ判定） |

### 調整例

- **玉の数を変える**：`MODES` の `balls` を書き換えます。
- **盤の色を変える**：`paintSurface` の中の `bg.addColorStop(...)` を書き換えます。
